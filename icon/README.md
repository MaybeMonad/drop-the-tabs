# Icons

Extension icons should be placed here:

- `16.png` — Toolbar icon (16x16)
- `32.png` — Toolbar icon retina (32x32)
- `48.png` — Extension management page (48x48)
- `128.png` — Chrome Web Store (128x128)

## Recommended

Create a simple icon with:
- Primary color: `#3B82F6` (blue-500)
- Simple stacked/layers motif
- Transparent background

Or use a tool like:
- Figma
- Iconify
- Heroicons
